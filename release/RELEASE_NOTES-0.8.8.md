# 方律案件看板 0.8.8

本版扩展刑事量刑辅助测算的首批罪名，并改进退出和更新收尾。

- 新增掩饰隐瞒、敲诈勒索、非法拘禁、聚众斗殴、妨害公务、开设赌场、非法吸收公众存款、集资诈骗、强迫交易；完善寻衅滋事，合计覆盖22个罪名。
- 分别核验构成条件、法定刑档位、责任主体、地域及时间效力；保留人工基准刑和依据输入、开放性条件及广东地方增量的人工判断。
- 独立测算记录保存事实、依据、人工确认、计算过程和执行指纹。旧记录保留原结论，列表统一正确显示北京时间。
- 正常关窗通过后台完成服务停止与数据库写入收尾后退出，重复退出请求只收尾一次。
- 更新回执目录已由当前用户所有时，不再重复设置所有者；仍校验受保护DACL及仅当前用户访问。

量刑输出用于律师辅助审查。定罪条件、量刑起点与人工核验基准刑分开处理，历史案件、刑种、附加刑、缓刑及开放性条件依界面要求逐项核验。

Windows安装包提供updater minisign签名；该签名与Windows Authenticode代码签名不同。
