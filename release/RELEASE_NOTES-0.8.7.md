# 方律案件看板 0.8.7

本版完成“刑事量刑辅助测算”的计算边界修正，并补上升级测试发现的当前版本 WAL 安全恢复问题。

## 刑事量刑辅助测算

- 结果页分开展示法定刑、量刑起点、人工核验基准刑和月数调节结果。
- 除危险驾驶罪外，测算前必须填写人工核验的基准刑区间及来源；旧地方细则的自动增刑月数已停用。
- 多个一般量刑情节按同一基准刑合并计算，并校验认罪认罚合并幅度、累犯最低增量、法定刑上下限及冲突情节。
- 无期徒刑、死刑、管制、单处罚金和免予刑事处罚不再被统一换算成有期徒刑月数。
- 职务侵占罪、非国家工作人员受贿罪增加 2026 年司法解释时间效力核验；普通财产犯罪和电信网络诈骗的数额档位改为人工确认。
- 每条保存记录附带规则版本、内容指纹、法源、人工依据和计算过程；案件页可以展开查看历史测算。

## 升级安全

- 当前版本异常退出后如留有完整 WAL/SHM，应用会先核验物理结构、校验和、迁移谱系和数据库完整性，再进行内容寻址备份及独占 checkpoint。
- 同一迁移 SQL 因 Windows 构建产生的 LF/CRLF 换行差异可安全兼容，既有迁移历史不会被改写。
- WAL 不完整、校验失败、迁移谱系不兼容或数据库完整性异常时仍会在写入前停止，不会自动删除、覆盖或绕过保护。

## 安装

关闭正在运行的方律案件看板后，运行 `FanglvCaseBoard_0.8.7_x64-setup.exe` 覆盖安装。原有案件数据不会随安装包删除。
