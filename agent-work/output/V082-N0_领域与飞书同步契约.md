# V082-N0 领域与飞书同步契约

状态：已冻结为 0.8.2 实施输入

基线：`origin/main` / `55ad19990d1c48af0f892e387709edd46b5b3694`

## 1. 领域事实源

- 案件领域只认 `cases.legal_domain`。
- 民事 `cases.workflow_status` 不再承担刑事程序阶段。
- 刑事程序阶段只认 `criminal_case_profiles.current_stage`。
- `case_stage_items.domain` 必须等于所属案件 `legal_domain`；历史飞书阶段只有在绑定案件领域明确时才纠正。
- 管理状态 `cases.management_status` 与程序阶段分离。

## 2. 刑事程序阶段

0.8.2 使用以下稳定值：

1. 收案委托
2. 侦查
3. 审查逮捕
4. 审查起诉
5. 一审
6. 上诉及二审
7. 再审/审判监督
8. 执行
9. 待确认

历史中文、英文和带“阶段”后缀的值在业务入口归一化；无法可靠归一的值显示为“待确认”，不得猜测。

## 3. 飞书字段方向

- `local_only`：legal_domain、本地 Case ID、文件夹名称/路径、材料、OCR/抽取全文、聊天、记忆、凭据。
- `feishu_readonly`：公式、查找、汇总和飞书系统字段。
- `bidirectional_review`：案件名称、管理状态、程序阶段、案由/罪名、当事人、承办机关、关键日期。
- 进展、阶段、联系人允许人工确认的双向新增/更新；物理删除不双向传播。
- 所有本地到飞书写入必须由当前设备上的用户动作触发；NAS 复制不得触发外部调用。

## 4. 发布前置门禁

- 刑事案件不能写入民事 workflow_status。
- 阶段新增、更新、读取和排序均通过领域门禁。
- 飞书写回在领域门禁通过前保持不可用。
- 任何字段决定均保存基线、前值、后值、操作者、方向和执行结果。
