# v0.8.7 刑事量刑辅助测算加固与发布验收

日期：2026-09-11

说明：量刑加固最初形成于 `v0.8.6-fanglv` 候选；正式数据库安装验收发现当前版本 WAL 恢复和 Windows 迁移 SQL 换行兼容问题后，旧标签保持不可变，修复版升为 0.8.7 并正式发布。

## 变更边界

- 本工具定位为律师内部的单罪量刑辅助，不输出量刑承诺，不替代完整阅卷、法律适用和裁判判断。
- 计算链固定区分“法定刑—量刑起点—人工核验基准刑—量刑情节调节—裁判情景模拟”。
- 除危险驾驶罪可直接采用一个月至六个月拘役幅度外，不再根据现行适用状态未核实的旧地方细则自动生成“增加刑罚量”或基准刑。
- 普通财产犯罪和电信网络诈骗的数额档位由律师人工确认；职务侵占罪、非国家工作人员受贿罪采用法释〔2026〕6号参照标准前，必须显式确认时间效力依据。
- 定性情节没有全国统一可直接套用幅度时停止数值测算，不虚构百分比。

## 法律规则修正

- 多个一般量刑情节以同一基准刑为基数，同向相加、逆向相减；未成年人等修正情节在先依次调节。
- 认罪认罚与指定相关从宽情节的合并从宽幅度按60%封顶，其他独立情节不被错误吞并。
- 累犯增加基准刑10%至40%，低端增量一般不少于三个月；未成年人犯罪与累犯互斥，过失犯罪不适用一般累犯。
- 只有从轻情节时不得突破本档法定最低刑；存在可减轻情节时按下一法定刑幅度校正。
- 月数区间不吞并无期徒刑、死刑、管制、单处罚金等不同刑种；“0个月”只用于法定明确的免予刑事处罚。

## 可追溯性

- 每次结果保存完整输入、过程、输出、规则集版本、引擎版本、规则内容 SHA-256、核验法源、时间效力选择和人工基准刑来源。
- 案件内增加历史测算查看；旧记录缺少规则版本时明确标为“未版本化”，不伪造补齐。
- 保存继续采用追加独立记录和刑事画像 revision 冲突保护，不回写刑事画像或案件阶段。

## 升级阻断修复

- 当前版本异常退出留下完整 WAL/SHM 时，先做物理结构、校验和、迁移谱系、数据库完整性核验和内容寻址备份，再独占 checkpoint；任何一步不成立均在写入前停止。
- 对迁移 0066—0068 只兼容同一内嵌 SQL 的 LF/CRLF 两种精确 SHA-384，不放宽其他字节差异，也不改写 `_sqlx_migrations`。
- `v0.8.6-fanglv` 标签固定在 `c34a0af74a5506ecbd994c3b7e8da7e807478cf5`；正式 `v0.8.7-fanglv` 固定在 `42a843e88ae05788cf02ed99f2bea4f125b501d9`。
