# 23 V083-S1 主控验收量表

## P0 拒绝条件

- 任一包失败后留下部分业务写入，或关闭外键约束绕过循环引用。
- 依赖闭包仍可被 500 条边界拆开并写出必败事件。
- 同一确定性失败继续无限重试、重复新增 active 隔离或仍记录 `succeeded`。
- 自动暂停未阻止后台调度，或失败推进最近业务成功时间。
- 隔离/日志/UI 泄露业务正文、密钥、Token、解密载荷或敏感绝对路径。
- 修改正式数据库/NAS/同步组、飞书或任务范围外生产代码。

## P1 拒绝条件

- 迁移 0063 缺少幂等约束/索引，active 去重依赖竞态性的“先查后插”。
- resolved 生命周期无法追溯，或用户恢复无需明确动作。
- 接收端已有依赖与包内依赖没有一致判定，重放不幂等。
- 稳定错误码只靠中文文案分类，后端/UI/审计语义不一致。
- N0 专项测试通过方式是删除、弱化或绕过原失败断言。

## 必跑门禁

- S1 定向 Rust 测试及设备同步契约。
- `cargo check --lib -j 1`。
- `cargo clippy --lib -j 1 -- -D warnings`。
- Windows Rust 清单脚本。
- `pnpm test:logic`、`pnpm build`、`pnpm validate:source`。
- `git diff --check`、修改范围审计、独立只读审计。

## 可延后到 RC

- 正式双设备/NAS 两轮收敛（必须使用正式库在线一致性副本和全新隔离同步目录）。
- Windows UI 视觉确认和签名安装包/updater 验证。

以上延后项不得在 S1 报告中宣称已通过。
