# 01 项目简报

## 目标

发布 v0.8.3 数据安全热修复，解决：

1. 同编号不同 SQL/未知 checksum 导致启动迁移崩溃；
2. case/contact 循环外键及 500 条分包导致设备同步基线无法导入；
3. 飞书孤立绑定导致本地预演、解绑事务回滚；
4. 对上述修复完成 Windows、旧库升级、双设备收敛和签名发布门禁。

## 非目标

- 元典定时后台刷新和账户周期固化；
- 无关功能、UI 重构或顺手清理；
- 直接修复唯一正式数据库或当前 NAS 失败组。
