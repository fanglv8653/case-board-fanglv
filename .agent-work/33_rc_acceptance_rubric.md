# 33 V083-RC 验收量表

## P0 拒绝

- 任一源码/Windows Rust/迁移/设备同步门禁失败仍声称可发布。
- 在唯一正式库、当前 NAS 失败组或正式飞书资源上做试验。
- 未验证签名、版本、哈希、latest.json 与 updater 链即发布或上传资产。
- 将本地模拟冒充两台正式设备收敛，或将 unsigned bundle 冒充签名产物。

## P1 拒绝

- 全新库、0.8.2 正常形状、兼容 checksum、不兼容谱系任一缺少启动/升级证据。
- 双端两轮收敛、重复幂等、失败回滚、隔离恢复任一缺少临时资源自动化证据。
- 版本源不一致，或 release gate 未实际执行。
- 报告未区分本地通过与外部资源阻塞。

## 本地接受

- 全部本地自动化与隔离模拟门禁通过，独立复审无 P0/P1。
- 工作树只含计划内 RC 证据/版本改动并提交；无正式资源访问。

## 最终发布接受

- 在用户确认的在线一致性副本、新隔离同步目录和两台正式设备上完成两轮收敛及幂等。
- 两端安装前备份数据库、同步凭据和组元数据，回滚路径可用。
- 正式签名安装包、updater 资产、latest.json 的签名/版本/哈希及 0.8.2→0.8.3 在线升级全部通过。
- 未满足上述任一项时状态只能是 `blocked_external`，不得发布或恢复正式设备同步。
