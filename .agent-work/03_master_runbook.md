# 03 主控运行手册

1. 按 `00→01→02→03→05→08→09` 顺序恢复上下文。
2. 只从 `09_dispatch_board.md` 派发 todo 任务。
3. 上游契约任务先行；允许并行的任务必须具有不重叠写入范围。
4. Worker 开始后自行将状态改为 `inProgress`，完成后提交 `submitted_for_review`。
5. 主控逐文件审查、运行任务级测试、检查越权写入后决定 accepted/rejected。
6. 驳回必须说明缺失项、修改文件、复验命令及是否允许原线程继续。
7. 每轮结束更新主摘要、项目日志、Git 状态和下一轮任务切片。

## 冲突规则

- 多 Agent 共享工作树；发现他人修改不得覆盖、重置或回滚。
- 迁移编号、公共错误码和公共测试脚本由主控统一合并。
- 同一文件禁止并行写；发生重叠立即暂停较晚任务并重新切片。
