## 未完成的正式发布验收

1. 当前进程环境中 `TAURI_SIGNING_PRIVATE_KEY` 与 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` 均不存在，因此没有生成或伪造 NSIS updater `.sig`；Windows Authenticode 也未配置。
2. 需要由受控 CI 在冻结的发布提交/tag 上生成精确资产 `FanglvCaseBoard_0.8.4_x64-setup.exe` 及同名 `.sig`，完成 minisign、SHA-256、helper 安装落位和隔离升级验证。
3. 必须在可启动 Rust 测试二进制的 Windows 环境重跑全量测试；当前机器的 `0xc0000139` 是进程装载阶段错误，不可用链接成功冒充断言通过。
4. 必须在无正式凭据的 VM/全新测试用户中完成 0.8.3→0.8.4 更新、取消、断网、签名错误、收尾失败、成功提示至多一次、数据库 quick_check 和无残留进程验收。
5. 上述验收和用户明确发布授权完成后，才可创建/复用 draft Release、公开 Release，并由发布脚本在独立提交中同时更新 `release/version.json` 与 `release/latest.json`。
6. 飞书首次正式绑定仍需用户在 0.8.4 界面生成全量只读预览，逐项确认历史记录和案件映射；开发/RC 阶段没有自动导入或改写正式表。
