# 25 V083-S1 返工 B 主控验收量表

## P0 拒绝项

- 任一故障点重试会重新 seal 同序列，或要求人工删除 NAS 文件才能继续。
- NAS 已落盘而 SQLite 无可验证草稿；SQLite 最终确认存在部分提交路径。
- 同名不同字节会被覆盖、删除或静默认领。
- outbox operation 集、前序 hash、设备或序列不一致仍可推进 CAS。
- 命令返回、UI 或审计可出现绝对路径、密钥、解密正文或底层数据库错误正文。
- 故障注入只断言错误码，没有证明文件字节、草稿、outbox、sequence 与 manifest hash 的前后状态。
- 同实体动作顺序仍由随机 UUID 或非单调时间裁决；同事件重复 operation_id 可被静默跳过。
- 连续 judge 操作发生后项冲突时会丢失前项成功值，或 revision/hash 与最终实体不一致。

## P1 拒绝项

- 多包恢复会重写已完成包或跳过未完成序列。
- 并发创建可生成两份同序列随机信封。
- 草稿无唯一键、状态约束、FK 或清晰回收语义。
- 只覆盖 event-only 或 DB 回滚中的一种故障，没有覆盖 manifest-only、两文件齐全和第二包中断。
- 为通过测试改用确定性 nonce、关闭加密随机性、放宽签名/manifest 链校验。
- 本地 export 隔离成功后不能严格 resolve，或 manual_review 没有脱敏、可审计的人工作用入口。
- 把瞬时 Database/NAS 错误一律自动暂停，或让持久化 planner 损坏无限重试。

## 接受证据

- 上述八类故障/安全反例逐项实际通过。
- 迁移语义 sentinel 和 lookalike 反例随后由独立迁移线程通过。
- 独立只读审计未发现新的 P0/P1。
- 全部规定门禁零失败；真实 NAS/双设备验证仍明确延期到 RC。
